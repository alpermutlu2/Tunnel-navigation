Through the Tunnel · v0.5.3

Simulator runs

Each card opens one simulated drive (seed 0): the true car next to the phone's estimate, the sensor data the phone records, and the exit callout. Press Play on the page; the scrubber jumps to any moment. Numbers on the cards are 50-seed Monte Carlo results. Live parameter changes need the local server (python tools/serve.py).

All drives are simulated. "At diverge" is the along-track error where the exit branch leaves the main tunnel (straight-tunnel performance); "at portal" is where the car comes out. Callouts are announced when the estimate plus 1.65 σ reaches the callout point, so they err early, never late. The "where it breaks" numbers come from 30-seed stress runs in the repository's reports.
